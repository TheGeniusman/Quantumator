# Quantumator auf iPhone & iPad (Web-App, läuft offline)

1. Im GitHub-Repository: main.py, engine.py, make_pwa.py (Upload files) und
   .github/workflows/ios-web-app.yml (Create new file) hinzufügen.
2. Settings -> Pages -> "Source": GitHub Actions wählen.
3. Tab "Actions": "Quantumator iPhone/iPad Web-App veröffentlichen" laufen lassen (ca. 3-6 Min.).
4. Die Adresse (https://<name>.github.io/<repo>/) in Safari öffnen, warten bis der Rechenkern geladen ist
   (1. Mal ca. 50 MB), dann Teilen -> "Zum Home-Bildschirm". Ab jetzt funktioniert die App ohne Internet.
